01

项目概览

求职系统策划作品：自研一套可落地、可验证、可玩的抽卡系统框架

S

背景 Situation

求职系统策划，需体现数值建模与资源经济全链路能力；市面上常见抽卡方案卡池单一、缺乏体系化设计。

T

任务 Task

从零自研可落地的抽卡系统框架，并交付可玩 DEMO 验证设计。

A

行动 Action

设计五类卡池与三类资源经济；建立分池保底；蒙特卡洛仿真 10000 次验证综合概率与大保底触发率；"结果先行"随机方案 + 6 张配置表驱动盘面与奖池版本化；Godot 4.6.3 独立开发可玩 DEMO。

R

结果 Result

交付完整设计文档、配置表、仿真曲线与可玩 DEMO，形成"设计—配置—验证—可玩"闭环。

02

系统设计亮点

四大核心设计支撑抽卡系统从框架到可玩落地

🃏

五类卡池

普池 / 自选 / 年限 / UP 池分层设计，覆盖不同付费与成长阶段。

💰

三类资源经济

一类券养留存、二类券作核心付费、三类券担周年联动冲刺，活动结束自动结转货币。

🎯

节点集中消费

形成"节点集中消费 + 长线囤积"闭环的货币经济循环。

🔢

数值仿真验证

蒙特卡洛仿真 10000 次，综合概率与大保底触发率与公示口径自洽。

03

分池保底设计

按不同卡池区分保底门槛，兼顾稳定预期与付费节奏

普池 / 自选 / 年限硬保底
90抽

90 抽硬保底，超出后必出高级物品，保障体验下限。

UP 池小保底 / 大保底
60 · 120抽

60 抽小保底、120 抽大保底，双段保障 UP 目标。

紫色保底固定
10抽

紫色品质 10 抽保底，稳定中端奖励节奏。

软保底曲线指数 · 系数 3.5
软保底

指数软保底（3.5）按池区分起点，命中前概率平滑抬升。
