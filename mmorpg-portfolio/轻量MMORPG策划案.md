## 一、项目概述

### 1.1 项目背景与立项依据
《杖剑传说》的高流水展示了轻量级MMORPG在市场的潜力——其上线半年仍保持App Store畅销榜前60名，验证了"轻度放置×轻度MMO"品类的商业可行性。《剑与远征：启程》则证明了赛季制内容驱动模式在长线运营中的有效性，其上线首月即收获超1500万下载、1.58亿美元收入。当前市场缺少一款同时具备**大世界探索自由度**与**技能Build深度策略**的二次元Q版轻量MMORPG，本项目正是瞄准这一空白。

### 1.2 游戏定位与核心卖点
一款二次元Q版轻量MMORPG，核心体验为"回合制自动战斗 + 战前阵型与技能Build构筑 + 大世界探索"。

三大核心卖点：
1. **技能自由搭配的Build深度**：战前配置阵型站位与8个技能槽的主动/被动装配，4种基础职业 × 2种职业偏向 × 7种元素组合产生海量构筑路线，回合制自动战斗让策略重心前移至战前Build阶段；
2. **神像驱动的探索式大世界**：三块大陆以神像为锚点连接，未解锁神像的区域为"迷失之地"（单人体验），解锁后回归"真实世界"（多人社交），探索本身即是社交入口；
3. **赛季制长线运营**：每赛季引入新地图、新技能、新机制，赛季等级重置但保留永久成长，兼顾新老玩家体验。

### 1.3 目标用户画像
- **核心用户**：18-30岁，偏好二次元Q版美术风格、追求轻度策略搭配但不愿被日常任务绑架的上班族/学生党；时间碎片化，喜欢单人推进与多人社交结合的体验。
- **潜在用户**：放置/卡牌RPG玩家（受《杖剑传说》《AFK Journey》吸引）、开放世界探索爱好者、二次元美术收藏向玩家。
- **不适合人群**：追求高强度操作竞技的硬核PvP玩家、偏好写实画风的玩家。

### 1.4 平台与引擎
- **平台**：移动端优先（iOS/Android），后续视市场表现考虑PC端跨平台互通。
- **引擎**：Unity 2022 LTS+，成熟生态支撑移动端3D渲染与网络同步，二次元Q版角色渲染（Toon Shader）社区方案丰富。

### 1.5 商业模型
免费游玩 + 内购（F2P + IAP），核心付费结构：
- **技能抽卡**：核心付费深度来源，多层级卡池设计（基础/高级/赛季/特权池），重复获取转化为养成资源；
- **月卡/战令**：持续付费锚点，提供日常资源产出加成与赛季专属奖励；
- **外观付费**：时装、武器幻化、宠物等纯外观向付费，不影响数值平衡；
- **限时礼包**：根据玩家进度精准推送的破冰/成长礼包。

## 二、世界观与背景设定

### 2.1 世界观概述
世界名为**原初世界**，由远古诸神共同创造。诸神将自己的力量凝结为神像散布于三块大陆各处，神像既是世界的稳定锚点，也是连接诸领域的枢纽。

然而一场名为**"断离"**的灾变撕裂了世界的法则——部分区域的现实结构崩塌，陷入"迷失之地"状态：这些区域与现实脱节，身处其中的人无法感知到其他存在，仿佛独自游荡在世界的残影之中。唯有触碰并激活该区域的神像，才能将迷失之地重新锚定回真实世界，恢复与其他冒险者的联系。

世界基调：明亮温暖的二次元奇幻风格，以"探索与连接"为核心情感驱动——玩家的每一步探索都在修复破碎的世界。

### 2.2 核心阵营与势力
三块大陆各有一个主导国度，以及贯穿全大陆的守序/混沌二元对立势力：

| 大陆 | 主导国度 | 特色与理念 | 对应元素偏向 |
|------|---------|-----------|-------------|
| 晨曦大陆 | 晨曦王国 | 信仰光之神，崇尚秩序与守护，以骑士团与圣殿为核心组织 | 光、水、物理 |
| 灼砂大陆 | 灼砂联邦 | 信仰火之神，崇尚力量与自由，以竞技与锻造为核心文化 | 火、风、物理 |
| 苍流大陆 | 苍流议会 | 信仰水之神，崇尚智慧与探索，以法师学院与航海贸易为核心 | 水、雷、暗 |

- **深渊教团**（敌对势力）：崇拜"深渊"力量的异端组织，认为迷失状态才是世界的本真形态，破坏神像，意图将世界沉入深渊。主线核心反派。
- **守望者议会**（中立势力）：诸神陨落后的遗留组织，由各国度学者与守护者组成，为冒险者提供指引、发放任务、维护传送阵网络。

> 国度货币（详见5.3）由三国度分别发行，玩家在不同国度商店使用对应货币消费。

### 2.3 地理与区域划分
原初世界存在三块大陆及诸多小岛，彼此靠传送阵连接。大世界散布诸神像，触碰神像可祝福地块，激活后显示其他玩家；未解锁神像的地块属于迷失之地，玩家无法遇见其他玩家，解锁神像后回归真实世界。野外分布固定地点副本和资源点，以及探索宝箱和野怪刷新点。

- **三大陆分布**：晨曦大陆（起始区域，新手引导）、灼砂大陆（中段区域，PvP与锻造文化）、苍流大陆（高阶区域，魔法与深海探索）；
- **小岛与秘境**：散布于大陆之间的独立小岛，部分需特殊条件解锁，多为隐藏副本与稀有资源点；
- **主城**：每块大陆一座主城，为多人社交区域（始终处于真实世界状态），提供商店、拍卖行、社交功能；
- **野外区域分级**：每块大陆按神像分布划分为多个区域，区域内含固定副本入口、采集点、宝箱、野怪刷新点；区域间以自然地形（山脉、河流、悬崖）作为天然边界。

### 2.4 核心剧情脉络
- **序章**：玩家以"流浪者"身份在晨曦大陆的迷失之地苏醒，无记忆，仅本能地被神像吸引。激活第一座神像后，世界恢复色彩，遇到守望者议会的引导者，得知自己是"觉醒者"——能感知并修复断离的特异存在。
- **晨曦篇**：调查晨曦大陆的断离源头，发现深渊教团在暗中活动，试图阻止神像激活。揭开第一块大陆的历史与诸神陨落的线索。
- **灼砂篇**：穿越至灼砂大陆，此地断离更为严重，部分区域已彻底失序。在此接触锻造文化，获取更强装备与技能，发现断离与远古战争遗迹的关联。
- **苍流篇**：深入苍流大陆的深海秘境，寻找诸神遗留的核心真相——"断离"并非灾变，而是诸神最后封印某物的代价。
- **终章（赛季引入）**：封印松动，更大的威胁浮现。后续剧情随赛季推进，每赛季揭露新的世界真相。

## 三、核心玩法循环

### 3.1 大循环（长期追求）
角色成长（等级/装备/技能/命座） → 挑战更高难度内容（副本/世界Boss/赛季内容） → 获取稀有资源（技能晶石/高级装备/升华之石） → 角色成长

**赛季大循环**：进入赛季 → 赛季等级成长（101→180） → 赛季专属内容挑战 → 赛季结算（等级重置，转化为永久加成） → 永久成长积累 → 新赛季

### 3.2 中循环（单次游戏会话）
登录 → 领取离线挂机收益 → 日常任务/周常任务 → 副本挑战（单人/组队） → 大世界探索（神像/宝箱/采集） → 公会活动（公会战/公会讨伐） → 社交/交易 → 下线

### 3.3 小循环（战斗/操作）
选择关卡 → 战前配置 → 自动战斗 → 奖励结算

**战前配置**（核心策略阶段）：
- **阵型选择**：设置角色站位，分前排/后排；前排承受近战攻击，后排受保护但部分技能无法攻击前排目标；站位直接影响受击顺序与技能可达性；
- **技能装配**：选择8个技能槽装配（主动技能排序 + 被动技能生效），根据关卡特性调整Build和主动技能释放顺序；
- **消耗品预设**：可预设战斗中自动使用的药剂（如血量低于30%自动使用治疗药剂），每种药剂每场战斗限用1次。

**自动战斗**（回合制）：
- 回合制自动执行，双方按**行动速度**决定出手顺序；
- 主动技能按预设顺序在冷却完成后自动释放，被动技能持续生效；技能冷却以回合为单位计算；
- 每场战斗设有**回合上限**（常规30回合，公会Boss50回合），超过回合上限判负或按剩余血量比例判定结果；
- 组队战斗中各玩家角色按各自速度插入统一行动序列。

**战斗结算**：
- 根据剩余血量比例、使用回合数评定星级（3星/2星/1星），星级影响奖励倍率；
- 速刷（少回合通关）是PvE核心追求，驱动玩家优化Build搭配。

## 四、角色系统

### 4.1 职业设计
角色创建时仅选择**基础职业**（主手武器固定），副手槽位在20级前锁定。20级进阶时选择副手类型，决定职业偏向（转职），此后Build方向与可抽技能元素范围均围绕所选偏向展开。

| 基础职业 | 主手武器 | 职业偏向 | 副手武器 | 定位 |
|---------|---------|---------|---------|------|
| 战士 | 剑 | 斗士 | 短剑 | 近战物理输出，以伤害次数或暴击触发特效为核心 |
|        |        | 骑士 | 盾牌 | 近战防御坦克，以格挡反击或格挡回复为核心 |
| 射手 | 弓 | 游侠 | 箭袋 | 远程持续输出，多段射击与元素附加 |
|        |        | 刺客 | 匕首 | 近远程切换爆发，高闪避高机动（闪避特化） |
| 法师 | 杖 | 术士 | 法书 | 多元素AOE魔法输出，范围伤害核心 |
|        |        | 贤者 | 十字架 | 光暗双系，光为治愈、暗为伤害，兼具辅助与输出 |
| 召唤师 | 鞭 | 驭灵使 | 纹章 | 召唤体为主要输出，以召唤数量与持续时间见长 |
|        |        | 暗术师 | 手套 | 本体为主要输出，光暗召唤物提供辅助效果 |

转职规则：
- **1-19级（转职前）**：仅使用主手武器进行基础战斗，技能池仅含主手通用技能（物理系基础技能），让玩家先体验基础操作再决定发展方向；
- **20级转职**：选择副手类型即为转职，转职后副手槽位解锁，对应职业偏向的技能池开放抽取，元素偏向随之确定（详见4.3技能系统）；
- **转职变更**：转职后副手类型固定，如需变更需消耗命运晶石进行重置（详见4.4角色养成系统）。

### 4.2 属性框架

**一级属性**：生命、攻击、防御、行动速度

- 行动速度决定回合制战斗中的出手顺序，速度越高越先行动；
- 速度差距过大时可能出现一回合内连续行动（速度差 ≥ 2倍时，高速方额外行动1次）。

攻防计算公式：
```
if 攻击力 > 目标防御力 × 2:
    伤害 = 攻击力 × 0.8 - 目标防御力 × 0.2
else:
    伤害 = 攻击力 × (攻击力 / (攻击力 + 目标防御力))
```

**二级属性**：伤害减免%、伤害加成%、治疗加成%、暴击、暴击伤害加成%、暴击抗性、格挡、格挡伤害抵抗%、破甲、闪避、命中

判定概率公式：
```
暴击率 = 暴击 / (暴击 + 目标暴击抗性)
格挡率 = 格挡 / (格挡 + 目标破甲)
闪避率 = 闪避 / (闪避 + 对方命中)  // 计算上限60%，通过技能/药剂加成最高上限90%
```

最终伤害计算：
```
if 触发闪避:
    最终伤害 = 0
else:
    最终伤害 = 伤害 × (1 + (伤害加成 - 伤害减免))
    if 触发格挡:
        最终伤害 = 最终伤害 × (1 / (格挡伤害抵抗 + 1))
    if 触发暴击:
        最终伤害 = 最终伤害 × (1 + 暴击伤害加成)
```

**三级属性**：各类元素亲和、元素抗性

### 4.3 技能系统

#### 4.3.1 卡池设计

技能通过抽取获得，卡池分为四类：

| 卡池 | 说明 | 保底机制 |
|------|------|---------|
| 特权池 | 可在所有自身职业技能中自选一个技能作为目标技能 | 保底必出目标技能晶石（该晶石转化为50对应技艺领悟），抽取必为完整技能晶石 |
| 赛季池 | 当前赛季技能池，赛季结束后该池技能可通过其他卡池获取 | 必出传说品质技能晶石 |
| 高级池 | 可自选某一阶段的技能作为卡池 | 必出该阶段传说品质技能晶石 |
| 基础池 | 所有技能都可抽取 | 必出传说品质技能晶石 |

卡池NPC为职业导师，抽卡表现为"技艺传授"。每次传授获得若干随机技能领悟/技艺晶石，技能领悟满后或获得对应技艺晶石可解锁对应技能。抽到已有技艺晶石将自动转化为对应等级的技艺领悟（蓝20、紫30、金50）。对应技能的领悟值满后可进行升星，星级满后可进阶到下一品质（具备如精英+、史诗+、传说+、神话+的中间品质，如史诗满星后品质提升为史诗+，史诗+满星后再提升至传说）。

#### 4.3.2 技能品质

| 品质颜色 | 品质名称 |
|---------|---------|
| 蓝 | 精英 |
| 紫 | 史诗 |
| 金 | 传说 |
| 红 | 神话 |
| 闪 | 觉醒 |

- 技能达到觉醒品质后，大部分技能会有机制上的提升或巨大的数值提升；
- 技能可直接获取的品质最高为金，要达到更高等级需消耗重复技能领悟提升；
- 所有技能都可提升至觉醒。

#### 4.3.3 技能槽

每个玩家具备8个随等级开放的技能槽（初始3个，20级/40级/60级/80级/100级分别各开放1个），可自由填入被动或主动技能。

- **1-19级**：仅有3个初始技能槽，且仅可装配主手通用技能（基础技能）；
- **20级转职后**：解锁副手技能池，第4个技能槽同时开放；
- **主动技能**：可自由决定装配顺序，战斗时按预设序列在冷却完成后自动释放；技能冷却以回合为单位（如冷却2回合 = 跳过2次行动后可再次释放）；
- **被动技能**：始终生效；

进入赛季后，技能槽末尾会添加4个额外技能槽，此技能槽具备额外效果，其中两个存在仅赛季技能可装配的限制。

赛季槽位额外机制（待选）：
- **祝福槽位**：该槽位的技能得到加强（可选是否有条件限制，如限制攻击技能或元素类型）；
- **槽位组件**：向槽位装配组件来影响该槽位上的技能效果；
- **槽位联动**：该槽位触发时，会以50%的效率触发联动的另一槽位；
- **蜕变槽位**：该槽位技能机制将得到改变。

#### 4.3.4 元素偏向

技能包括元素区分，元素包括物理、水、火、风、雷、光、暗。

1-19级转职前仅可使用主手通用技能（物理系）；20级转职后根据所选职业偏向解锁对应元素范围：

| 基础职业 | 职业偏向 | 可用元素 |
|---------|---------|---------|
| 战士 | 斗士（短剑） | 物理、火、风 |
|        | 骑士（盾牌） | 物理、水、光 |
| 射手 | 游侠（箭袋） | 物理、火、雷 |
|        | 刺客（匕首） | 物理、风、暗 |
| 法师 | 术士（法书） | 水、火、风、雷 |
|        | 贤者（十字架） | 光、暗 |
| 召唤师 | 驭灵使（纹章） | 水、火、风、雷 |
|        | 暗术师（手套） | 光、暗 |

> 贤者特殊规则：治愈系均为光元素技能，暗元素技能均为伤害系。
>
> 「混沌元素伤害」该伤害计算元素抗性时，取对方最低的抗性。

### 4.4 角色养成系统

角色成长共经历5次进阶（20级/40级/60级/80级/100级），其中**20级为转职进阶，40-100级为命座进阶**，两者性质不同。

#### 4.4.1 转职（20级进阶）

- 20级进阶时，玩家从基础职业的两个职业偏向中选择一个（如战士→斗士/骑士），选择后副手槽位解锁，对应职业技能池开放抽取，元素偏向随之确定；
- 转职选择即确定此后所有Build方向的基础，后续命座均在此偏向内深化；
- **转职重置**：消耗**命运晶石**可重置转职选择（变更职业偏向），重置后副手技能池切换，已装配的副手技能自动卸下并存入技能背包，命座不受影响但可能与新偏向不匹配（需重新审视命座搭配）。

#### 4.4.2 命座进阶（40/60/80/100级）

每次进阶可从两个天赋命座中二选一解锁。命座为永久被动效果，在当前职业偏向内进一步深化Build方向。

**设计原则**：
- 每次进阶的两个命座选项分别对应同一职业偏向内的不同发展路线，而非跨偏向选择；
- 命座效果覆盖：属性加成、技能机制改变、元素亲和强化、特殊触发条件等维度；
- **闪避特化**：闪避相关命座仅限射手（游侠/刺客）职业偏向，其他职业不出现闪避效果。
- **格挡特化**：格挡相关命座仅限骑士职业偏向，其他职业不出现骑士效果。
- **治疗特化**：治疗加成相关命座仅限贤者职业偏向，其他职业不出现治疗加成效果。

**各职业偏向Build路线总览**：

| 基础职业 | 职业偏向 | 路线A | 路线B |
|---------|---------|-------|-------|
| 战士 | 斗士 | 多段触发流（伤害次数触发特效） | 暴击触发流（暴击触发特效） |
| 战士 | 骑士 | 反击流（格挡反击、格挡提升格挡率） | 回复流（格挡回复、格挡叠加增伤） |
| 射手 | 游侠 | 多段射击流 | 元素附加流 |
| 射手 | 刺客 | 闪避爆发流 | 暗影连击流 |
| 法师 | 术士 | 多元素融合流 | 单元素极致流 |
| 法师 | 贤者 | 持续流（持续治愈+持续伤害） | 爆发流（单次高治愈+单次高伤害） |
| 召唤师 | 驭灵使 | 亡语流（召唤体死亡触发效果） | 增幅流（强化召唤体属性） |
| 召唤师 | 暗术师 | 同生流（主角与召唤体共生） | 强化流（强化本体，召唤体辅助） |


**命座重置**：
- 消耗**命运晶石**可重置已选命座，重新进行二选一（与转职重置共用命运晶石）；
- 命运晶石获取途径：赛季结算高评级奖励、高难度副本首通、世界Boss贡献排名、限时活动；
- 重置后原命座效果立即移除，新命座效果立即生效，无需重新升级。


### 4.5 外观与幻化系统

- **时装**：裁缝店获取，各国度特色时装可用国度货币购买；系统商城可用神晶购买；
- **武器幻化**：消耗外观券可切换武器显示外观，不影响武器属性；外观券通过活动、成就、商城获取；
- **宠物系统**：可协助参与战斗，提供辅助或输出，可消耗放生同种宠物获得的灵魂印记升星/强化，可通过喂食升级；通过活动、成就、商城、副本、挂机获取宠物蛋，宠物蛋在家园一段时间后孵化；
- **称号系统**：成就/赛季/活动获取，显示于角色名上方，部分称号附带轻微外观特效；
- **染色系统**：部分时装支持自定义主色调染色，染料或染料合成材料通过采集副职产出或商城购买。

## 五、成长系统

### 5.1 等级系统

- **基础等级（1-100）**：永久保留，通过主线/日常/副本/挂机获取经验；每20级一次进阶，每次进阶解锁一个技能槽；
- **赛季等级（101-180）**：赛季专属，进入赛季即解锁赛季技能槽；赛季结束后重置至100级，重置部分转化为永久加成（命座属性微增、基础属性百分比提升等）；
- **进阶验证**：每次20级进阶需完成对应的进阶试炼副本（单人），通关后进行转职/命座选择并解锁对应技能槽；
- **经验产出**：离线挂机产出基础经验（有上限），日常/周常/副本产出主要经验。

### 5.2 装备系统

#### 5.2.1 装备部位与属性

装备部位：主手、副手、头盔、胸甲、护腿、靴子、戒指、项链。

- **常规部位**（除项链和戒指）：每件装备1个主属性 + 1个副属性 + 4个其他属性词条；
- **项链/戒指**：只有1个主属性 + 2个词条，这两个词条主要为稀有属性（二级属性）词条或特效词条。

#### 5.2.2 装备品质

白（普通）→ 绿（精良）→ 蓝（稀有）→ 紫（史诗）→ 金（传说）→ 红（神话）

#### 5.2.3 套装与宝石

- **套装效果**：部分装备具备套装效果，套装效果可消耗一套套装被提取为对应的特殊宝石，概率成功；
- **宝石镶嵌**：共9个宝石镶嵌位（8个常规宝石槽 + 1个特殊宝石槽）；特殊宝石槽装备时，会将当前套装效果替换为该宝石对应的套装效果；宝石镶嵌不随装备切换变化；
- **宝石合成**：可消耗3个同等级宝石合成更高一级宝石，概率成功。

#### 5.2.4 装备强化

- **精炼**：消耗同名装备精炼，获得更高的属性；
- **强化**：装备强化等级绑定装备槽位，不随装备切换而改变；
- **升阶**：装备可消耗若干更高等级装备提高等级，每20级一个阶段，每个阶段跃升需额外消耗特殊道具**升华之石**。

#### 5.2.5 装备获取与处理

- **获取**：副本掉落（主要）、世界Boss掉落、锻造师合成、活动奖励、交易行购买；
- **词条重铸**：消耗特定材料可重铸装备的随机词条，主副属性不可重铸；
- **装备分解**：不需要的装备可分解为强化/精炼材料，高品质装备分解产出稀有材料。

### 5.3 货币系统

| 货币 | 定位 | 产出途径 | 主要用途 |
|------|------|---------|---------|
| 古金币 | 常规货币 | 日常任务、副本、怪物掉落、出售装备 | 装备强化、宝石合成、基础商店消费 |
| 紫金币 | 主要货币 | 周常、高难度副本、活动、竞技场 | 购买传承之证、高级商店消费、拍卖行交易 |
| 神晶 | 付费货币 | 仅充值获取（1元=10神晶） | 时装、礼包、限时商城消费 |
| 国度货币 | 区域货币 | 对应国度完成任务、参与国度活动 | 购买国度特色时装、国度专属材料、国度商店稀有道具 |
| 初级传承之证 | 抽卡货币 | 日常任务、宝箱奖励、紫金币购买、活动、赛季奖励 | 在基础池抽取技能 |
| 高级传承之证 | 抽卡货币 | 周常任务、宝箱奖励、活动、赛季奖励、竞技场、世界Boss、礼包 | 在高级池抽取技能 |
| 特权传承之证 | 抽卡货币 | 赛季奖励、礼包、剧情任务、活动 | 在特权池抽取技能 |
| 神赐传承之证 | 抽卡货币 | 周常任务、活动、紫金币购买、礼包 | 在赛季池抽取技能 |

古金币产出可略大于消耗；紫金币产出受控。传承之证可通过紫金币购买或游戏内活动获取，也可通过礼包直接获取。

### 5.4 生活技能系统

每升5级获得1点技能点，可自由选择加到对应的副职技能上。消耗紫金币可重置生活技能点分配，每周限一次。

#### 采集者
影响大世界采集、击杀魔物获得资源的数量和品质。

| 技能等级 | 解锁效果 |
|---------|---------|
| 5级 | 自动采集（离线挂机采集） |
| 10级 | 稀有材料采集产出加倍 |
| 15级 | 采集品质+1级 |
| 20级 | 专属材料获取（用于合成顶级消耗品） |

#### 锻造师
影响装备合成的消耗和词条重铸消耗。

| 技能等级 | 解锁效果 |
|---------|---------|

| 10级 | 合成/精炼消耗-10% |
| 15级 | 套装提取成功率+20% |

影响宝石获取概率和宝石合成成功率。

| 技能等级 | 解锁效果 |

## 六、内容系统

### 6.1 任务系统

- **主线任务**：贯穿三大陆的核心剧情线，推进解锁新区域、新系统、新副本；主线含剧情演出与关卡战斗，为玩家提供成长主线引导；
- **支线任务**：各区域独立故事线，提供世界观补充与稀有奖励（技能晶石、命运晶石碎片等）；部分支线为隐藏触发，需探索发现；
- **日常任务**：每日刷新，3-5个简单目标（完成副本、采集资源、击败野怪等），奖励古金币、经验、少量紫金币；
- **周常任务**：每周刷新，目标难度更高（完成高难度副本、参与公会战、完成区域探索等），奖励紫金币、宝石、传承之证；
- **世界任务**：周期性刷新的区域事件任务，需区域内多名玩家协作完成（击杀精英怪、击杀Boss、护送NPC、收集资源），完成后全区域玩家获得奖励。

### 6.2 副本/地下城系统

所有副本战斗均采用回合制自动战斗，进入前需配置技能序列，可存储三套方案。

| 副本类型 | 人数 | 回合上限 | 说明 |
|---------|------|---------|------|
| 训练副本 | 1人 | 无限制 | 自由调整假人数量和数值，验证个人Build强度与技能序列 |
| 单人副本 | 1人 | 30回合 | 剧情关卡与进阶试炼，验证个人Build强度，产出装备与经验 |
| 组队副本 | 4人 | 30回合 | 日常装备产出核心途径，含普通/困难/噩梦三档难度（噩梦可开启噩梦2、噩梦3额外强化难度，提高掉落倍率）；不强制战法牧铁三角，允许同职业组队；支持自动匹配与手动招募 |
| 团队副本 | 6人（分为3个双人小队） | 40回合 | 周常高难度内容，含多场Boss战与路线配合，产出传说品质装备与稀有材料；每周限次挑战，首通额外奖励 |
| 混沌试炼 | 12人 | 50回合 | Boss挑战，每周轮换Boss池，每日挑战；根据造成伤害产出基础资源及赛季代币等，适合"大佬带新人"社交场景 |
| 羁绊之塔 | 2人 | 30回合 | 双人爬塔模式，每层难度递增，记录历史最高层数，阶段性获取奖励；每日刷新获取次数，破纪录全服奖励，每周重置主题；适合"大佬带新人"社交场景 |
| 爬塔玩法 | 1人 | 30回合 | 单人无限挑战，每层难度递增，记录历史最高层数，层数奖励为一次性获取 |

### 6.3 开放世界玩法

- **神像激活**：核心探索驱动力，激活神像后区域从"迷失之地"转为"真实世界"，解锁多人社交、区域商店、传送点；首次激活获得一次性探索奖励；
- **宝箱与解谜**：激活神像后可进行，散布于各区域的隐藏宝箱（普通/精致/华丽），部分需解谜（推箱子、元素机关、密码等）开启；解谜可消耗道具跳过；
- **野怪与精英怪**：固定刷新点普通野怪（产出材料/经验），随机刷新稀有精英怪（产出高品质装备/宝石）；满足一定条件刷新族群Boss，Boss出现时全区域广播，激活后限时出现；
- **采集点**：大世界固定采集点（矿石/草药/木材/兽皮），采集品质受采集者副职等级影响；采集点有冷却刷新时间；
- **世界Boss**：每日定时定点刷新的区域世界Boss，全服玩家可参与，按伤害贡献排名结算奖励；
- **探索成就**：区域探索度（激活神像/开宝箱/解谜/击杀精英），100%探索解锁区域专属奖励，国度100%探索解锁专属称号。

### 6.4 PvP 系统

轻度PvP定位，以异步回合制与排名为主，不设开放世界强制PvP：

- **竞技场**：异步1v1回合制排名赛，匹配战力相近的对手防守阵容，阵容可见，赛季槽位不可用；回合上限20回合，超时按剩余血量比例判定；赛季制，每赛季重置排名，段位奖励为紫金币与称号；战前配置阶段为核心策略——需根据对手阵容调整站位与技能序列；
- **荣誉对决**：双方使用相同技能池进行回合制对战，纯策略比拼，消除养成差距；回合上限15回合；每日限次，奖励为传承之证；
- **赛季巅峰赛**：赛季期间开放的PvP模式，解锁赛季槽位使用权限，采用BO3赛制（三局两胜）；对手搭配仅第一个技能槽和最后一个技能槽可见，增加阵型与技能序列的策略深度；每局回合上限20回合；
- **自由切磋**：主城/安全区域可发起友好回合制切磋邀请，无奖励，纯社交与测试Build用（无法对开启挂机模式的角色发起）；
- **公会战**：两种多人异步公会战模式，具体详见7.2公会系统。

### 6.5 赛季/资料片结构

- **赛季周期**：每赛季持续约3个月，分为前/中/后三个阶段，各阶段解锁不同内容；
- **赛季前置内容**：新地图区域（1-2个新区域/国度）、新主线剧情章节、新技能（加入赛季池）；
- **赛季中期内容**：新赛季副本、新世界Boss、赛季专属活动玩法；
- **赛季末期内容**：赛季结算评级、赛季商店兑换、成就回顾；
- **赛季重置**：赛季等级（101-180）重置至100，赛季技能槽关闭，赛季专属道具/货币过期；重置时根据赛季评级、剩余赛季资源等结算赛季积分，可在赛季商店兑换特殊资源（如抽卡资源、永久属性提升等）；
- **赛季奖励**：赛季评级（根据赛季等级、副本进度、PvP排名综合评定）决定奖励品质，高评级获得命运晶石、限定称号、限定时装等稀有奖励。

## 七、社交系统

### 7.1 组队与匹配

- **自动匹配**：副本支持自动匹配同战力玩家，无职业限制，多同职业可组队；
- **手动招募**：通过世界频道/公会频道/好友列表发布招募信息，可设置战力门槛与职业偏好；
- **跨服组队**：高难度副本与团队副本支持跨服匹配，扩大匹配池；
- **队伍上限**：常规组队4人，团队副本6人，混沌试炼12人，羁绊之塔2人，世界Boss不限参与人数；
- **离线收益共享**：组队状态下，队友离线后仍可获得部分关卡收益，组队挂机采集点会获得效率提升，鼓励固定队伍维持。

### 7.2 公会系统

#### 7.2.1 基础设定

- **创建条件**：消耗紫金币创建，创建者为会长；初始成员上限30人，公会等级提升可扩展至60人，更多人数消耗神晶购买提升，最高90人；
- **公会等级**：通过公会成员日常活跃、公会战、公会活动积累公会经验提升等级；升级解锁公会技能、公会商店商品、成员上限；
- **公会技能**：会长消耗公会资金升级，全体成员生效（如经验加成、掉落加成、副本伤害加成等）；
- **公会仓库**：成员可捐赠装备/材料换取公会贡献点，贡献点用于兑换公会商店商品；
- **公会讨伐**：全公会成员共同挑战公会Boss（回合上限50回合），根据讨伐进度全公会获得奖励，参与即获基础奖励；可随时进出不耽误进度（后台自动战斗）；战前需配置阵型站位与技能序列；
- **公会日常**：公会养宠/种植等挂机助力玩法，产出稀有养成材料，增强归属感；
- **任务悬赏**：公会成员可通过公会发布悬赏进行更高级道具的交易与悬赏（不包括常规道具，有最低门槛），系统收取20%手续费，提高VIP等级最高可衰减至5%，手续费自由选择由买家/卖家支付。

#### 7.2.2 公会战——驻地防守模式（两天）

公会会长/副会长在结束后报名，报名后第二天开战
匹配两个公会开启驻地防守，公会成员自行选择防守驻点：

| 驻点类型 | 数量 | 每点防守人数 | 解锁条件 |
|---------|------|------------|---------|
| 主基地 | 1个 | 4名 | 默认 |
| 一级驻点 | 4个 | 3名 | 5级公会 |
| 二级驻点 | 8个 | 2名 | 3级公会 |
| 三级驻点 | 16个 | 1名 | 默认 |

- 会长或副会长（两名）可消耗战术能量为某一驻点添加增益；
- 未选择驻守驻点的成员可选择后勤驻点增加战术能量产出；
- 会长或副会长在开战前可调整成员驻守情况，调整后系统自动发送邮件通知对应成员；
- 成员可自由选择攻打敌方驻点，多人驻点可选组队挑战；
- 胜利获得公会段位积分，段位越高该公会每日奖励越高（段位决定资源最高品质）；
- 公会驻地防守竞技段位每赛季结算并重置（类似王者荣耀的段位重置）。

#### 7.2.3 公会战——夺金模式（每周）

- 匹配四个公会开启夺金模式；
- 公会成员自行选择与己方占领区域相邻区域进行攻略，攻略成功后占领该区域；
- 每个区域有不同的每日产出，最终结算期产出越多的公会排名越高，获得奖励越多；
- 结算奖励为一次性获取，参与奖励每日获取；
- 每周四开启，周一结算，周二周三休赛；
- 根据本次夺金排名获得段位积分，优先匹配段位接近的公会，段位越高结算奖励越多；当前赛季历史最高段位提升时全公会成员获得奖励；
- 公会夺金竞技段位每赛季结算并重置（类似王者荣耀的段位重置）。

### 7.3 聊天与社交关系

- **频道分类**：世界频道（全服）、区域频道（当前区域）、公会频道、队伍频道、私聊；世界频道有冷却限制防止刷屏；
- **好友系统**：可跨服添加好友，好友列表显示在线状态与所在区域；好友组队获得额外经验加成；
- **师徒系统**：高等级玩家可收低等级玩家为徒，师徒共同完成副本/日常可获得额外奖励；徒弟达到指定等级后出师，师父获得师徒点数可兑换稀有道具；
- **关系系统**：好友亲密度达标后可申请创建关系，创建关系后获得专属好友标识，解锁关系专属社交动作和表情；
- **黑名单**：可屏蔽指定玩家的聊天与招募信息。

### 7.4 交易与拍卖行

#### 7.4.1 交易行（30级开放）

- **可售物品**：大部分材料、宝石、幻化、消耗品等可交易物品；
- **定价**：价格有上下限限制，参考前一日市场均价浮动；
- **寄售时间**：24小时；
- **求购**：可设置求购，求购优先高价匹配，其次先到先得；
- **结算维护**：每日固定时间结算维护（约10分钟），期间暂停交易。

手续费（由卖家支付）：

| 每周收入区间 | 普通用户 | 商会会员 |
|-------------|---------|---------|
| 0 - 3000 | 10% | 5% |
| 3000 - 8000 | 20% | 10% |
| 8000以上 | 25% | 15% |

#### 7.4.2 拍卖行

- **可售物品**：装备、高稀有度物品等；
- **定价**：自由定价，使用紫金币竞价；
- **寄售时间**：6小时，可自选是否设置一口价；
- **竞价**：玩家竞价，竞拍者可随时加价，时间结束后价高者得；
- **通知**：竞拍者出价被超过后邮件提示 + 红点提示；
- **手续费**：与交易行一致。

#### 7.4.3 邮件系统

支持物品附件发送，系统奖励/拍卖行交易通过邮件发放；邮件保留999天。

### 8.2 通货膨胀控制

- **赛季重置回收**：赛季等级重置回收赛季养成资源，转化为永久加成而非直接保留，避免数值无限膨胀；
- **多层级货币隔离**：古金币（基础）、紫金币（进阶）、神晶（付费）三层隔离，基础货币膨胀不直接影响高级资源；
- **交易行手续费**：10%-25%阶梯式手续费直接回收货币，拍卖行手续费同等；
- **装备迭代消耗**：高等级装备升阶需消耗大量低等级装备与升华之石，持续消耗装备库存；
- **绑定机制**：关键养成道具（技能晶石、命运晶石、升华之石）为账号绑定，不可交易，防止市场操控；
- **限时消耗活动**：定期推出消耗活动（如锻造大赛、宝石合成狂欢），激励玩家消耗囤积资源。

## 九、技术需求与美术风格

### 9.1 引擎与网络架构

- **引擎**：Unity 2022 LTS+，支持移动端渲染管线（URP），Toon Shader实现二次元Q版渲染；
- **客户端架构**：前后端分离，客户端负责渲染与输入，服务端负责逻辑验证与状态同步；
- **网络同步**：主城/野外区域采用状态同步（服务端权威），战斗场景采用帧同步或状态同步（视延迟测试结果决定）；
- **多人同屏**：主城区域支持50-100人同屏，野外区域支持20-30人同屏；超出时采用LOD降级与视野裁剪；
- **反作弊**：服务端验证所有战斗结算与交易，关键数值（伤害、掉落）由服务端计算；客户端仅负责表现层；
- **数据存储**：玩家数据云端存储，支持多设备登录与数据同步。

### 9.2 美术风格与视觉目标

- **整体风格**：二次元Q版3D，角色比例约3头身，场景风格明亮温暖，色彩饱和度适中，参考AFK Journey的绘本质感与杖剑传说的日式奇幻氛围；
- **角色设计**：4个职业造型辨识度高，副手装备有独立外观表现；角色表情丰富，待机/移动/战斗/受击动画流畅；
- **场景设计**：三大陆风格差异明显——晨曦大陆（明亮草地+白墙城堡）、灼砂大陆（沙漠+红岩+熔岩）、苍流大陆（深海+蓝紫色调+魔法学院）；迷失之地区域采用灰雾/低饱和度滤镜，激活神像后恢复色彩，形成强烈视觉对比；
- **战斗特效**：7种元素各有独立配色与粒子风格（火-橙红/水-蓝白/风-青绿/雷-紫黄/光-金白/暗-紫黑/物理-银灰），技能特效华丽但不光污染，暴击/格挡/闪避有清晰反馈；
- **UI风格**：扁平化设计，圆角卡片，柔和渐变，主色调与当前所在大陆主题色联动。

### 9.3 性能与适配

- **最低配置**：Android 8.0+/iOS 12+，4GB RAM，骁龙660/同等级芯片；
- **推荐配置**：Android 11+/iOS 15+，6GB+ RAM，骁龙845/同等级芯片；
- **包体控制**：首包控制在1.5GB以内，后续资源按区域动态下载（进入新区域时加载对应资源包）；
- **发热控制**：战斗场景限制同屏特效数量，低帧率模式（30fps）可选，离线挂机时不渲染3D场景降低功耗；
- **加载优化**：区域间传送使用异步加载+进度条，主城预加载高频资源。

## 十、运营与商业化

### 10.1 付费点设计

| 付费类型 | 价格区间 | 内容说明 | 设计目标 |
|---------|---------|---------|---------|
| 月卡 | 30元 | 每日产出紫金币+经验加成5%，持续30天 | 持续付费锚点，中低氪首选 |
| 战令（赛季通行证） | 68元 | 赛季专属任务线奖励，含限定时装/称号/传承之证 | 赛季活跃驱动，中氪主力 |
| 破冰礼包 | 6元 | 首充6元礼包，含紫色技能晶石+古金币+经验药 | 新手破冰转化 |
| 成长礼包 | 30-128元 | 根据玩家等级阶段推送，含传承之证/宝石/强化材料 | 阶段性付费提升 |
| 限时礼包 | 6-328元 | 新技能池上线/赛季开始时推送，含对应抽卡资源 | 精准推送付费转化 |
| 外观付费 | 12-128元 | 时装/武器幻化/宠物/染色，纯外观无数值 | 外观收藏向付费 |
| 技能抽卡 | 消耗传承之证（可用紫金币购买） | 核心付费深度，多层级卡池 | 核心收入来源 |

设计原则：
- **外观不卖数值**：时装、幻化、宠物纯外观，不影响PvP公平性；
- **付费加速而非付费独占**：所有数值养成内容均可通过游戏内获取，付费仅加速获取速度；
- **精准推送**：礼包根据玩家当前进度与卡点推送，而非无差别弹窗；
- **免费玩家友好**：日常/周常/活动产出足够的基础抽卡资源，保证零氪玩家每赛季可获得3-5次十连抽。

### 10.2 活动运营框架

- **节日活动**：春节/暑期/万圣/圣诞等节点，推出限时活动副本、限定时装、登录奖励；活动持续2-3周；
- **赛季活动**：每赛季开启时配套赛季庆典活动（登录7天送传承之证、赛季首通奖励翻倍等），持续1-2周；
- **联动活动**：与二次元IP联动，推出联动限定技能/时装/宠物；联动期间配套剧情活动副本；
- **限时副本**：每月推出1-2个限时挑战副本，含独特机制与稀有奖励，限时结束后不定期复刻；
- **登录奖励**：日常签到（7日循环）+ 月度签到（累计登录天数奖励）+ 赛季签到（赛季累计登录奖励）；
- **玩家赛事**：赛季巅峰赛配套观战功能与赛事奖励，培养PvP社区氛围。

### 10.3 客服与社区

- **反馈渠道**：游戏内客服入口（支持截图/录像提交），官方社区论坛，社交媒体账号；
- **GM工具**：在线GM支持基础问题处理（物品丢失、账号异常），违规行为举报与处理系统；
- **玩家社区管理**：官方攻略站/Wiki维护，玩家创作激励计划（二创大赛/攻略征集），公会招募板块；
- **数据透明**：定期发布开发者笔记，公开技能/装备调整说明与未来赛季预告，建立玩家信任。
